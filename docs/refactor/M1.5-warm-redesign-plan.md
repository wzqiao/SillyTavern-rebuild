## 1. 设计原则（每一步都拿它量）

1. **傻瓜式**：配好 baseURL + key + 选模型 → 直接开玩。没有参数过载。
2. **渐进式披露**：首页只露常用项；高级项藏进二级「点进去才展开」。设置 = 分组清单。
3. **暖夜灯下**：暖棕底 + 蜜糖强调，护眼、可长时间待着。
4. **可读性优先**：不被立绘/装饰干扰文字（立绘铺底不做）。
5. **避开 AI 套路**：不用「奶油底+赤陶色+大衬线」那套默认脸（依据 Anthropic frontend-design skill）。

## 5. 建议执行顺序

**A（中文收尾）→ C（连接引导）→ D（聊天傻瓜化）→ B（设置清单）→ E（库简化）→ F（运行时接线/M2）**
